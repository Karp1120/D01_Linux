# Linux Administration Basics

Этот репозиторий содержит учебный проект по основам администрирования Linux.  
В рамках работы была установлена и настроена виртуальная машина с **Ubuntu 20.04 Server LTS** без графического интерфейса в **VirtualBox**.

Цель проекта — на практике разобраться с базовыми задачами системного администратора: установкой и обновлением системы, настройкой пользователей, сети, SSH, времени, мониторингом процессов, анализом дискового пространства, просмотром логов и работой с планировщиком заданий.

## О проекте

Во время выполнения проекта я последовательно настроил Linux-сервер и выполнил набор практических заданий, которые помогают понять, как устроена базовая работа с системой через терминал.

Работа охватывает как начальную настройку машины, так и повседневные административные задачи, с которыми можно столкнуться при работе с сервером.

## Что было сделано

### Part 1. Установка ОС
- Установлена **Ubuntu 20.04 Server LTS** без графического интерфейса.
- Проверена версия системы через команду `cat /etc/issue`.

### Part 2. Создание пользователя
- Создан новый пользователь, отличный от пользователя, созданного при установке.
- Пользователь добавлен в группу `adm`.
- Проверено наличие нового пользователя в системе.

### Part 3. Настройка сети ОС
- Задано новое имя машины.
- Настроена временная зона.
- Изучены сетевые интерфейсы системы.
- Рассмотрено назначение интерфейса `lo`.
- Получен IP-адрес, выданный DHCP.
- Определены внешний и внутренний адреса шлюза.
- Настроены статические параметры сети: IP-адрес, шлюз и DNS.
- Проверена работа сети после перезагрузки.
- Выполнен `ping` удалённых хостов для проверки подключения.

### Part 4. Обновление ОС
- Обновлены системные пакеты.
- Проверено, что после обновления новых пакетов для установки не осталось.

### Part 5. Использование sudo
- Новому пользователю выданы права на использование `sudo`.
- Из-под этого пользователя изменено имя хоста.
- Изучено назначение команды `sudo`.

### Part 6. Установка и настройка службы времени
- Настроена автоматическая синхронизация времени.
- Проверена корректность работы службы синхронизации.
- Подтверждено состояние `NTPSynchronized=yes`.

### Part 7. Использование текстовых редакторов
- Установлены и использованы три текстовых редактора:
  - `vim`
  - `nano`
  - третий редактор по выбору

- В каждом редакторе были выполнены основные действия:
  - создание файла,
  - сохранение изменений,
  - выход без сохранения,
  - поиск текста,
  - замена текста.

### Part 8. Установка и базовая настройка SSHD
- Установлена служба `sshd`.
- Добавлен автозапуск службы при старте системы.
- Изменён стандартный порт SSH на `2022`.
- Проверено наличие процесса `sshd`.
- Проверено, что служба прослушивает нужный порт после перезагрузки.
- Разобран вывод команды `netstat -tan`.

### Part 9. Использование утилит top и htop
- Установлены и использованы утилиты `top` и `htop`.
- По выводу `top` были определены:
  - uptime,
  - количество пользователей,
  - средняя загрузка системы,
  - количество процессов,
  - загрузка CPU,
  - использование памяти,
  - PID процессов с наибольшим потреблением памяти и процессорного времени.

- В `htop` были выполнены:
  - сортировка по разным параметрам,
  - фильтрация по процессу `sshd`,
  - поиск процесса `syslog`,
  - добавление отображения `hostname`, `clock` и `uptime`.

### Part 10. Использование утилиты fdisk
- Выполнен анализ информации о диске через `fdisk -l`.
- Определены:
  - имя диска,
  - размер диска,
  - количество секторов,
  - размер swap.

### Part 11. Использование утилиты df
- Исследовано дисковое пространство с помощью `df` и `df -Th`.
- Для корневого раздела определены:
  - размер,
  - занятое место,
  - свободное место,
  - процент использования.
- Определены единицы измерения и тип файловой системы.

### Part 12. Использование утилиты du
- Получены размеры каталогов:
  - `/home`
  - `/var`
  - `/var/log`
- Размеры просмотрены как в байтах, так и в удобочитаемом виде.
- Также выведен размер содержимого внутри `/var/log`.

### Part 13. Использование утилиты ncdu
- Установлена утилита `ncdu`.
- Выполнен анализ размеров каталогов `/home`, `/var` и `/var/log`.
- Результаты сопоставлены с выводом `du`.

### Part 14. Работа с системными журналами
- Просмотрены системные журналы:
  - `/var/log/dmesg`
  - `/var/log/syslog`
  - `/var/log/auth.log`

- Найдена информация о последней успешной авторизации:
  - время,
  - пользователь,
  - способ входа.
- Выполнен перезапуск службы SSHD.
- В логах найдено сообщение о рестарте службы.

### Part 15. Использование CRON
- Настроен запуск команды `uptime` каждые 2 минуты.
- Найдены записи о выполнении задания в системных журналах.
- Выведен список текущих задач CRON.
- После проверки все задания были удалены.
